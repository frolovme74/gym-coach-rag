# Benchmark

Заполняется на контрольной точке 2. Формат набора запросов и метрики описаны в [spec/tech/rag.md](../spec/tech/rag.md).

Планируемое содержимое:

```
queries.json   — тестовые запросы и идентификаторы релевантных документов
run.py         — расчёт Recall@k и MRR
results/       — результаты прогонов: дата, параметры, метрики
```
