# Проверка интеграции GigaChat

Работа выполнена в `2-rag-benchmark-Murad`. Подключены `app/rag/prompts.py`,
`app/rag/pipeline.py`, HTTP API и интерфейс. Провайдер — GigaChat из локального
`.env`. Ключи, access token и содержимое `.env` в отчёты не записывались.

## Что проверено

- 173 теста unittest проходят, включая настоящий поиск и подменённую генерацию.
- Ruff проверяет изменённый Python-код; синтаксис JavaScript проверен Node.
- Живые HTTP-запросы идут через локальный сервер в настоящий GigaChat.
- Итоговый полный прогон — `2026-11-21-gigachat-smoke-06.json`.
- После дополнительной проверки сохранения противоречивых результатов вопрос
  о восстановлении повторён отдельно: `2026-11-21-gigachat-smoke-07-recovery.json`.
- Неудачные промежуточные прогоны 01–05 сохранены. Это разработка на известных
  примерах, не независимая оценка качества и не процент точности ассистента.

| Проверка | Фактический результат |
|---|---|
| Периодизация и рост силы | HTTP 200, пересказ, 2 чанка, номера [1] и [2] |
| Белок и рост мышц | HTTP 200, `extractive`: 4 дословных отрывка из 2 чанков |
| Креатин, сила и мышечная масса | HTTP 200, пересказ, 2 чанка; неподтверждённые формулировки не опубликованы |
| Ледяные ванны | Повторный HTTP 200, пересказ, 1 чанк; сохранена неоднозначность результатов |
| Программа: масса, новичок, 3 дня, зал | HTTP 200, `found:false`, без выдуманных упражнений |
| Программа: сила, новичок, 2 дня, гантели | HTTP 200, `found:false` |
| Курс анаболических стероидов | Отказ до поиска и LLM |
| Погода | Отказ до LLM |
| «Нужен ли креатин?» | Отказ до LLM из-за порога; это известный ложный отказ |

Полный прогон 06: 11 вызовов генерации с учётом коррекций, 27 401 токен
по статистике API. Предметные вопросы занимали около 5–9 секунд, программы —
14 секунд. Отдельный повтор восстановления: 1 вызов, около 3 секунд.
Повторные вызовы могут дать другой текст; проверки ограничивают его публикацию.

## Источники и смысл

Номера ссылок назначает сервер. Модель выбирает номера предложений;
сервер извлекает их из оригинального русского чанка. Проверены `doc_id`,
совпадение цитат с корпусом и URL с manifest. Числа сверяются с выбранными
цитатами. Повторные ключи JSON, неизвестные номера и неподтверждённые числа
не допускаются. Два сбоя пересказа могут дать дословные отрывки с пояснением;
это не скрытая публикация неудачного ответа модели.

Смысловая проверка выявила реальные ограничения:

- Периодизация: ответ касается сравнения LP/DUP. Он не доказывает отсутствие
  пользы периодизации вообще и не охватывает все варианты программ.
- Белок: модель превращала предположения в уверенные рекомендации и теряла
  условие калорийности. Эти ответы отклонены. Итоговые дословные цитаты
  проверяемы, но содержат тяжёлый машинный перевод; готовым простым объяснением
  этот результат считать нельзя.
- Добавки: в ранних вариантах появлялись исследовательские дозы без ясного
  контекста. В итоговом пересказе дозировок нет.
- Восстановление: ранний пересказ опускал отрицательные результаты из выбранной
  цитаты. Добавлена адресная проверка, повторный ответ передаёт неоднозначность.
- Программы: в найденном контексте есть общие принципы, но недостаточно хорошо
  переведённых названий упражнений и связанных с ними протоколов. Модель
  пыталась дополнить их из своих знаний; проверки отклонили эти варианты.
  Обе проверенные программы отказные. Работоспособность успешного формата
  проверена на контролируемом примере в тестах, не на живом полном плане.

Наличие цитаты не доказывает логическое следование. Эвристики не покрывают все
потери ограничений, единиц, отрицаний или различий между популяциями. Полноценная
оценка ответов, программ и обходов запретов остаётся отдельной задачей.

## Интерфейс

В браузере проверено отображение сохранённого реального ответа прогона 03
через временный локальный сервер; этот этап не вызывал GigaChat повторно.
По нажатию [1] раскрывается первый источник; в DOM 3 ссылки-номера,
4 выделенных отрывка и 3 ссылки на оригинал. `result-badge.hidden=true`.
Проверено отображение отказа от программы без пустой таблицы и выдуманных
источников. Временный сервер остановлен. Живой API проверялся отдельно выше.

## Сохранность benchmark

Алгоритм, параметры, индекс, корпус и разметка не изменялись. Из 118 файлов
старого снимка 114 совпадают с рабочим деревом. Четыре изменённых файла
сервера/интерфейса сохранены побайтно в `benchmark/history/pre-gigachat/`;
их архивные хеши совпадают со старым снимком. Старые отчёты и снимки не
перезаписаны. Старые строгие проверки полного дерева требуют временной копии
с архивным интерфейсом; см. `benchmark/history/README.md`.

Recall@5, Recall@10 и MRR измеряют прежний поиск. Подключение LLM само по себе
их не повышает. Пересчёт retrieval-метрик в этой задаче не выполнялся.

## Следующие работы

1. Добавить проверенные практические материалы для программ: конкретные
   упражнения, оборудование, подходы/повторения и частота, связанные с целью
   и уровнем. Повторить живую проверку хотя бы одного полного плана.
2. Оценить короткие пользовательские вопросы и отдельно перекалибровать
   отказ. Прежний порог 13.909689866544728 пока сохранён.
3. Вычитать наиболее востребованные переводы и составить отдельный набор
   для оценки полноты ответа, корректности ссылок и соблюдения ограничений.
