# Исходный интерфейс до интеграции

`pre-gigachat/` хранит точные копии изменённых файлов интерфейса и API до
подключения GigaChat. Это архив для воспроизводимости, он не импортируется
сервером. Копии защищены собственным `manifest.json` и соответствуют старым
хешам из `retrieval-v3.1/original-files.json`, где эти файлы перечислены.

Ранее снимок эксперимента включил весь каталог `app/`, в том числе интерфейс,
который не участвует в ранжировании. Поэтому старые `verify_originals` и
`verify_parents` намеренно отвергают изменённый интерфейс текущего дерева.
Старые снимки и их проверяющий код не переписаны, проверки не ослаблены.
Чтобы воспроизвести старый эксперимент, создайте отдельную временную копию
проекта и замените в ней соответствующие файлы архивными. Не заменяйте ими
рабочий интерфейс в основной папке. Индекс, корпус, параметры, qrels и отчёты
benchmark при интеграции не изменялись.
