## 2026-10-10 — тема расширена: питание, добавки, восстановление

**Изменено**

- `spec/product/product.md`: четыре области знаний (`training`, `nutrition`, `supplements`, `recovery`), новые границы: без лечения, рецептурных препаратов, стероидов и допинга, без экстремальных диет, дозировки только из источников, персональное меню не составляется.
- `spec/product/scenarios.md`: основной сценарий охватывает все области; область показывается у источника; предупреждение о консультации с врачом при источниках о добавках.
- `spec/tech/rag.md`: один индекс на весь корпус, поле области у документа, латиница и дефис в токенах («BCAA», «омега-3»), ограничения в промпте, метрики по областям, запросы на отказ.
- `spec/tech/api.md`: у источника появилось поле `topic`.
- `data/corpus/README.md`: темы и требования к источникам по областям.
- `AGENTS.md`, `README.md`, `spec/tasks.md` приведены в соответствие.
- `app/stub.py`: поле `topic` у источников, демо-ответы о белке, креатине и сне.
- `app/static/`: примеры вопросов по одному на область, метка области у источника, предупреждение о добавках.
- `tests/test_api.py`: проверка поля `topic` и тест на ответ по каждой области.

**Проверено**

- `python -m unittest discover -s tests -v` — 10 тестов проходят.
- В браузере: вопрос о креатине даёт ответ, метки «Добавки» у источников и предупреждение; ошибок в консоли нет.

**Не сделано**

- Предупреждение о добавках и ответы о белке и сне в браузере по отдельности не просматривались — покрыты только тестами API.
- Отказ на вопросы о запрещённых средствах описан в спецификации, но не реализован: в заглушке он срабатывает лишь потому, что таких ключевых слов в ней нет.

## 2026-10-10 — новый интерфейс: тёмная тема и связанные с ответом источники

**Изменено**

- `spec/product/scenarios.md`: добавлены референсы, новый макет и требования к интерфейсу.
- `spec/tech/architecture.md`: записано решение о шрифтах с Google Fonts.
- `app/static/` переписан: тёмная тема с одним акцентным цветом; чипы-ссылки в тексте ответа, связанные с карточками источников (подсветка по наведению, раскрытие по нажатию); оценка BM25 числом и полоской; строка «N фрагментов из M документов»; параметры программы переключателями; программа карточками по дням; отдельное состояние «в материалах не найдено».
- Контракт API и сервер не менялись.

**Проверено**

- `python -m unittest discover -s tests -v` — 9 тестов проходят.
- В браузере пройдены три сценария: вопрос с ответом, вопрос вне корпуса, программа. Ошибок в консоли нет.
- Раскладка: на ширине 1280 px ответ и источники стоят в две колонки, горизонтальной прокрутки нет (проверено по размерам элементов); на ширине 457 px — в одну колонку (проверено по скриншотам).

**Не сделано**

- Десктопный вид не просмотрен глазами на полноразмерном скриншоте, только по геометрии элементов.
- Работа без сети (на системных шрифтах) не проверялась.
