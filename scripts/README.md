# Инструменты корпуса и проверки интеграции

`rag_smoke.py` — явная живая проверка HTTP API с GigaChat (расходует квоту):
`venv/rag/bin/python scripts/rag_smoke.py --live --output /tmp/gigachat-new.json`.
Сохраняет запросы, ответы, ссылки и статистику, без ключей; не перезаписывает
старые отчёты. Не является независимым benchmark качества.

Здесь оставлены только инструменты работы с источниками, сохранёнными переводами,
редакторскими решениями и чанками. Генерация ответа RAG находится в `app/`,
проверка поиска — в `benchmark/`. Локальных моделей перевода эти скрипты не требуют.

| Модуль | Зачем оставлен |
|---|---|
| `corpus_prepare.py` | Загрузка и очистка статей; общие операции JSON, подсчёт слов и проверка ветки |
| `corpus_quality.py` | Проверки чисел, единиц, пропусков, повторов и отрицаний; используется редактурой и тестами |
| `corpus_editorial.py` | Контекстные терминологические исправления и отделение исследовательской методики от тренировочных рекомендаций |
| `corpus_curate.py` | Применение сохранённых редакторских решений с проверкой хешей исходного текста |
| `corpus_review.py` | Проверка терминологии и команда редакторской сборки |
| `corpus_build.py` | Нарезка сохранённых переводов и происхождение каждого чанка |
| `corpus_validate.py` | Проверка корпуса, связей с оригиналами, границ и предобработки |
| `corpus_revision.py` | Воспроизведение исправленного корпуса v3 из old/new-патча в отдельную папку |

Удалены эксперименты Qwen/MLX, загрузчик OPUS/Argos, движок машинного перевода,
два requirements-файла для них и кеши переводчика. Общие проверки перенесены
из бывшего corpus_translate в corpus_quality без изменения их логики.
Удалены только два теста сегментации для удалённого движка; проверки данных сохранены.
Для поиска и тестов остаётся `requirements-rag.txt`.

Для воспроизведения v3 из сохранённых данных, из корня репозитория:

```bash
venv/rag/bin/python -m scripts.corpus_revision --output-dir /private/tmp/gym-corpus-rebuilt
```

Выберите новую несуществующую папку результата. Команда не перезаписывает
существующие документы и manifest. Зафиксированные версии корпуса/benchmark
нельзя пересобирать на месте: изменятся контрольные суммы экспериментов.
Старые corpus_build/curate/review нужны для происхождения исходной версии;
их команды записи предназначены для отдельной рабочей копии при новой ревизии.

Английские оригиналы, переводы, редакторские решения и отчёты сравнения моделей
сохранены как материалы исследования. Упоминания удалённых модулей в
CHANGE_HISTORY и замороженных README старых версий описывают прошлое состояние.
Повторный машинный перевод с нуля больше не входит в текущие возможности проекта.
