# gym-coach-rag

RAG-ассистент персонального тренера: отвечает на вопросы о тренировках в зале, питании, спортивных добавках и восстановлении и составляет программы тренировок — со ссылками на источники.

Учебный проект курса «НИРС 2026: разработка RAG-приложения с помощью LLM» (МГТУ им. Н. Э. Баумана).

## Состояние

Контрольная точка 1: документация и прототип интерфейса. Поиск BM25 и вызов LLM ещё не реализованы — сервер отдаёт демонстрационные ответы из заглушки (`app/stub.py`), интерфейс помечает их плашкой «Демо-данные».

## Запуск

Нужен Python 3.11+. Сторонних зависимостей нет.

```bash
python -m app
```

Интерфейс откроется на http://127.0.0.1:8000. Порт и адрес меняются флагами `--port` и `--host`.

## Проверка

```bash
python -m unittest discover -s tests -v
```

## Основной сценарий

1. Пользователь задаёт вопрос о тренировках, питании, добавках или восстановлении.
2. Система находит в корпусе релевантные фрагменты (BM25).
3. LLM формирует ответ только по найденным фрагментам.
4. Пользователь видит ответ и пронумерованные источники, на которые он опирается.

Второй сценарий — составление программы тренировок по параметрам (цель, уровень, число дней, оборудование). Подробнее: [spec/product/scenarios.md](spec/product/scenarios.md).

## Ограничение

Ассистент даёт справочную информацию и не заменяет врача, диетолога или очного тренера. Он не отвечает о лечении, рецептурных препаратах и допинге. Границы описаны в [spec/product/product.md](spec/product/product.md).
