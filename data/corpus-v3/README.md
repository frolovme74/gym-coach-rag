# Корпус v3: проверенные адресные исправления

599 чанков с прежними doc_id, темами и границами. В 21 чанке исправлен перевод
по сохранённым английским оригиналам: TR-024 (5), TR-026 (2), RE-006 (3), RE-018 (11).
19 чанков исправлены адресно, два о суперсетах переведены полностью заново.
Исправленные чанки содержат 350–521 слово по токенизатору corpus_prepare.
Полная смысловая вычитка всех 599 чанков и готовность к публикации не заявляются.

- `documents.json` — русский текст для автономного индекса v3.
- `manifest.json` — происхождение, новые хеши, parent_units и статус ревизии.
- `translation_patch.json` — old/new текст, причины правок, английские основания.
- `review.json` — проверка переводчика и перекрёстная проверка двух участников.

Разделены заминка (cool-down) и погружение в холодную воду; nap переведён как
дневной сон, lean body mass — безжировая масса. Исправлены названия упражнений,
различие силы и мощности и формулировка меньшего прироста после холодных ванн.
Сохранены условия исследований и ограничения переноса выводов на другие группы.
Несогласованность SMD и доверительного интервала в английском TR-024 отмечена
в тексте, а не исправлена догадкой. Внешние модели для этой ревизии не запускались.

Старые `data/corpus/` и `data/processed/ru/` сохранены для воспроизводимости.
Оригиналы находятся в `data/processed/en/`. Воспроизведение из патча в новую папку:

```bash
venv/rag/bin/python -m scripts.corpus_revision --output-dir /private/tmp/gym-corpus-v3-rebuilt
```

Команда откажется перезаписывать существующий корпус. Зафиксированный v3 также
не следует редактировать на месте: дальнейшую ручную правку сохраняйте новой
версией, затем обновляйте хеши, цитаты разметки и индекс. Для просмотра и поиска
ручных ошибок удобен `documents.json`, для сопоставления old/new — патч.

Одна прежняя negative-метка (test_re02/doc_re_006_008) требует переоценки после
уточнения nap. Она явно помечена в миграции разметки и сохранена только для
сравнения ранжирования на фиксированных метках; подтверждённой negative не считается.
