# Корпус

Заполняется на контрольной точке 2.

## Что нужно решить

- Какие материалы берём по каждой области: темы, объём, язык (русский).
- На каких условиях их можно использовать и хранить в открытом репозитории. Если лицензия не разрешает публикацию текста, в Git кладём только список источников и скрипт подготовки.

## Области и темы

Области должны быть представлены сопоставимым числом документов.

| Область | Код | Темы |
|---|---|---|
| Тренировки | `training` | техника базовых упражнений, объём и интенсивность, отдых между подходами, частота, прогрессия нагрузки, разминка, построение программ для новичков и среднего уровня |
| Питание | `nutrition` | калорийность под цель, норма белка, жиры и углеводы, питание до и после тренировки, вода |
| Добавки | `supplements` | добавки свободной продажи с изученным действием: для чего применяют, дозировки, ограничения |
| Восстановление | `recovery` | сон, дни отдыха, разгрузочные недели, мышечная боль после нагрузки, признаки перетренированности |

## Требования к источникам

- Для питания и добавок берём только материалы, которые сами ссылаются на исследования или официальные рекомендации; блоги и сайты магазинов не подходят.
- В корпус не входят материалы о рецептурных препаратах, анаболических стероидах, гормонах и допинге, о лечении травм и заболеваний, об экстремальных диетах.

## Формат

Один документ — один фрагмент (см. `spec/tech/rag.md`). Планируемый формат записи:

```json
{"doc_id": "doc_012", "topic": "nutrition", "source": "Название материала", "section": "Заголовок раздела", "text": "…"}
```
