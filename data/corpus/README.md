# Актуальный корпус

Единственный рабочий набор: `documents.json` (632 записи). Формат записи:

```json
{"doc_id":"doc_012","topic":"nutrition","source":"Название","section":"Раздел","text":"Текст фрагмента"}
```

599 научных чанков из 56 источников и 33 практические справки проекта находятся
в одной базе. `manifest.json` связывает doc_id с оригиналом, лицензией, абзацами
и редактурой. У справок отмечены `kind:project_guide`, `created_with_ai:true`,
ссылки на материалы и опорные документы; они не выданы за научные публикации.
Реестр и атрибуция — `../sources/`. Полная смысловая вычитка перевода не завершена.

Тексты редактируйте в `documents.json`. Связанные метаданные — в `manifest.json`.
Для общих дозировок `general_dose_passages` должны в точности совпадать с
проверенными предложениями текста. Каталог программ, правила FAQ и их
исключения также хранятся в manifest. Идентификаторы существующих записей
не меняйте без пересмотра ссылок и разметки benchmark.

Дополнительные карточки конструктора находятся в program-options.json. В них
хранятся упражнения по оборудованию, схемы нагрузки и тексты для цитирования.
Метаданные level_exercises связывают оборудование и уровень с допустимыми
вариантами групп knee и push. Идентификаторы ссылаются на записи каталога.
Идентификаторы должны быть уникальны среди всех карточек. Поиск по вопросам
индексирует documents.json, поэтому добавление карточек конструктора не меняет
профиль и разметку поиска.

После изменения из корня проекта:

```bash
python -m app.rag.build_index
python -m unittest discover -s tests -v
python -m benchmark.evaluate --output benchmark/results/new-check.json
```

Сборка проверит связность и обновит контрольные суммы профиля. Она не проверяет
научную правильность текста. Если текст размеченного фрагмента изменён,
benchmark потребует пересмотра свидетельств и хешей разметки; не обновляйте их
механически ради успешного теста. Новые релевантные попадания нужно разметить.

Оригиналы, полные переводы и промежуточная нарезка находятся в архиве вне проекта
(см. `../../spec/tech/maintenance.md`). Связи с исходными абзацами сохранены
в manifest. Для работы приложения оригиналы не требуются; для проверки
перевода используйте архив или первоисточник. Старые скрипты перевода/сборки
также доступны в архиве, но не являются текущей командой сборки.
