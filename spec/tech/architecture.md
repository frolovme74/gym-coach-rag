# Архитектура

Рабочее дерево содержит только текущую версию. Ранее зафиксированные изменения
остаются в Git; полный снимок до очистки (включая незакоммиченные материалы)
сохранён вне проекта. Местоположение и состав — `maintenance.md`.

## Компоненты

- `app/server.py`, `app/static/`: HTTP API и интерфейс без сборки.
- `app/llm.py`: клиент удалённого GigaChat, ключ только в локальном `.env`.
- `app/rag/preprocess.py`, `bm25.py`: нормализация, леммы и собственный BM25.
- `app/rag/retrieval.py`: расширение общими понятиями и сохранение индекса.
- `app/rag/runtime_retrieval.py`: приоритет справок по шаблонам вопроса.
- `app/rag/pipeline.py`, `prompts.py`: контекст, генерация, проверка цитат.
- `app/rag/planner.py`: каталог упражнений и проверка программ.
- `data/corpus/`: единственный актуальный корпус, manifest и профиль.
- `data/sources/`: реестр первоисточников и атрибуция.
- `benchmark/`: актуальные вопросы, разметка, оценка и ключевые отчёты.

## Сборка и запуск

`python -m app.rag.build_index` собирает ConceptBM25 по текущему профилю в
`data/index/bm25.json`. Старые корпуса для сборки не нужны. Сборка проверяет
связность документов, метаданных и цитат общих дозировок, затем обновляет
хеши профиля. Индекс не хранится в Git. `--plain-bm25` оставляет отдельный
учебный режим сборки базового BM25 с явными параметрами.

При запуске `python -m app` проверяются хеши корпуса, manifest и правил,
настройки и соответствие индекса. Если индекса нет, он строится в памяти.
Несовместимый существующий индекс вызывает ошибку.

## Зависимости

Python 3.11+, стандартная библиотека для HTTP/API. Для лемматизации используется
`pymorphy3` с русским словарём из `requirements-rag.txt`; это не поисковый индекс
и не переводчик. Локальных весов LLM нет. Модель по умолчанию — GigaChat-3-Ultra,
настройки в `.env` могут её переопределить. Интерфейс — HTML/CSS/JS; внешние
шрифты Google Fonts имеют системный запасной вариант.

## Проверка

`python -m unittest discover -s tests -v` проверяет действующие компоненты,
включая пример BM25 из методички. `python -m benchmark.evaluate --output PATH`
сравнивает текущий поиск с сохранённым финальным отчётом. Проверяются и чистый
ConceptBM25, и выдача с приоритетом справок. Живые вызовы LLM — отдельная явная
команда `scripts/rag_smoke.py --live`, расходующая квоту.

Подробное поведение и ограничения — `rag.md`, `integration.md`, контракт — `api.md`.
