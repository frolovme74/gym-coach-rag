# Сценарии и интерфейс

## Сценарий 1. Вопрос тренеру (основной)

Вопрос может относиться к любой из четырёх областей: тренировки, питание, добавки, восстановление (см. `product.md`). Область пользователь не выбирает — поиск идёт по всему корпусу.

1. Пользователь открывает приложение, видит вкладку «Вопрос» и поле ввода с примерами вопросов — по одному на область.
2. Вводит вопрос, например «Сколько отдыхать между подходами?» или «Сколько белка нужно в день?», и нажимает «Спросить».
3. Система ищет в корпусе фрагменты, релевантные вопросу, и передаёт лучшие из них в LLM.
4. Пользователь видит ответ с номерами-ссылками и источники: номер, область, название документа, фрагмент текста.
5. Если ответ опирается на материалы о добавках, под ним показано предупреждение о консультации с врачом.

**Результат:** короткий ответ, каждое утверждение которого можно сверить с фрагментом.

## Сценарий 2. Программа тренировок

1. Пользователь переходит на вкладку «Программа».
2. Выбирает цель (сила, мышечная масса, выносливость), уровень (новичок, средний), число дней в неделю (2–5) и оборудование (тренажёрный зал, только гантели).
3. Нажимает «Составить программу».
4. Система формирует поисковый запрос из параметров, находит фрагменты и просит LLM собрать программу по ним.
5. Пользователь видит программу по дням: упражнения, подходы, повторения — и источники.

**Результат:** программа под заданные условия со ссылками на материалы, из которых взяты принципы.

## Сценарий 3. В корпусе нет ответа

1. Пользователь задаёт вопрос вне корпуса: не по теме, о лечении травмы или о запрещённых препаратах.
2. Поиск не находит достаточно релевантных фрагментов.
3. Система сообщает, что в материалах ответа нет, и не генерирует ответ «от себя». Список источников пуст.

## Ошибки ввода

| Ситуация | Поведение |
|---|---|
| Пустой вопрос | Запрос не отправляется, под полем подсказка |
| Вопрос длиннее 500 символов | Сервер отвечает ошибкой, интерфейс показывает её текст |
| Сервер недоступен | Сообщение «Не удалось получить ответ», введённый текст сохраняется |

## Интерфейс

Одна страница, два режима: «Вопрос» и «Программа». Это инструмент, а не лендинг: первый экран — сразу поле вопроса.

### Референсы

| Сайт | Что берём |
|---|---|
| [Ladder](https://www.joinladder.com) | Настроение: почти чёрный фон, один кислотно-лаймовый акцент, широкий жирный гротеск капсом, кнопки-пилюли |
| [Perplexity](https://www.perplexity.ai) | Механику цитирования: номерные чипы в тексте, связанные с панелью источников |
| [Examine](https://examine.com) | Сигналы доверия рядом с ответом |
| [Hevy](https://www.hevyapp.com) | Вид программы: день — карточка, упражнения — строки таблицы |
| [Linear](https://linear.app) | Исполнение тёмной темы: тонкие границы вместо теней, плотная типографика |

Чего не берём: фотографии, маркетинговые блоки, списки сносок только внизу страницы, источники, спрятанные за «+N».

### Требования к интерфейсу

Ответ и источники:

- источники видны рядом с ответом без дополнительных кликов; на десктопе панель источников остаётся на экране при прокрутке ответа;
- номер в тексте ответа — кнопка-чип; наведение или фокус подсвечивает карточку источника с тем же номером, нажатие раскрывает её фрагмент целиком и прокручивает к ней;
- связь работает и в обратную сторону: наведение на карточку источника подсвечивает её чипы в тексте;
- у каждого источника показаны номер, область (тренировки, питание, добавки, восстановление), название документа, оценка BM25 числом и полоской относительно лучшего результата, фрагмент текста (свёрнут до трёх строк, раскрывается нажатием);
- над ответом — строка доверия: сколько фрагментов и из скольких документов использовано;
- если среди источников есть материалы о добавках, под ответом стоит предупреждение: посоветоваться с врачом перед приёмом, особенно при хронических заболеваниях, беременности и до 18 лет;
- если ответа нет, вместо текста — отдельное состояние «в материалах не найдено», панель источников скрыта.

Программа:

- параметры выбираются переключателями, а не выпадающими списками: все варианты видны сразу;
- день — карточка с таблицей «упражнение — подходы × повторения»;
- пояснение к программе содержит такие же чипы-ссылки на источники.

Общее:

- тема только тёмная; акцентный цвет один, используется для главного действия, чипов и оценок;
- заголовки — широкий гротеск Unbounded капсом, текст — Manrope; оба шрифта с кириллицей, при недоступности сети подставляются системные;
- пока поиск и LLM не подключены, в блоке ответа стоит пометка «Демо-данные»; в шапке пометок нет;
- предупреждение об ограничениях видно на каждом экране;
- всё доступно с клавиатуры, фокус виден; анимации отключаются при `prefers-reduced-motion`;
- страница работает на телефоне (от 360 px) и на десктопе.

Файлы прототипа: `app/static/index.html`, `app/static/style.css`, `app/static/app.js`.
